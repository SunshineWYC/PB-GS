# 设计与组件使用

默认英文、白底、低饱和蓝色强调。用图解释方法，用表或曲线支持主张，用交互帮助看差异；不要堆装饰、重复图或介绍网页制作过程。

正文行高 1.75；标题 1.3。桌面容器最大 1080px，超宽屏 1120px，平板两侧 20px，手机 16px。摘要、方法、结果和局限共用边界。调整 CSS 顶部的语义变量，不到处添加独立字号。

首屏标题尽量两行，但不以压小字体或移动端强制换行换取这一形式。短标题可一行，长标题自然多行。Teaser 直接插图，价值句放在图下；默认不为 Teaser 和方法总览添加放大按钮及操作性小字。

## 组件契约

- **标签切换**：每组独立 tablist；tab ID、aria-controls 和 panel 的 aria-labelledby 成对且全页唯一。按钮名使用真实场景名；左右/Home/End 可切换，无自动跳走。
- **图片查看**：给图像链接添加 data-lightbox；href 指高清版本，img src 指预览。alt 是具体图意，不写“Select image to enlarge”。对话框可查看原尺寸，Escape 关闭。
- **图片比较**：复制完整 data-image-compare 容器，替换左右图、标签及 alt。两图同场景、同视角、同纵横比；CSS 百分比裁剪保证缩放不改变图像坐标。鼠标/触摸直接拖动，键盘操作画面中的分隔线，没有额外位置滑条。
- **视频**：普通视频保留 controls、playsinline、muted 和 poster；preload=none。没有真实视频时删除模块，不添加空 src。
- **动态比较**：从 components/optional-sections.html 复制。输入是左右拼接的单个同步视频，左为基线、右为本方法，总尺寸 2W×H。每个容器独立画布和位置；默认手动播放，按需添加 data-autoplay，减少动态效果偏好优先。绝不可把任意比例视频当成 2W×H 直接裁剪。
- **表格**：原表截图和 HTML 表格二选一。截图保留列名、数值、单位、图例；HTML 表格放入 table-scroll，避免挤压正文。窄屏允许表格局部滚动。
- **引用**：代码文本是唯一来源，复制按钮读取当前条目；样式不改变 BibTeX 内容。

无 JavaScript 时保留静态图、表和原视频；标签面板展开。组件是可选的，不要为了保留模板功能虚构展示内容。
