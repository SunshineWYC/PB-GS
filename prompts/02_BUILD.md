# 按材料与方案制作网页

读取 AGENTS.md、PROJECT_BRIEF.md、notes/content-plan.md、notes/source-map.md 和 notes/decisions.md，基于已确认的材料完成 site/ 中的论文项目页。没有内容方案时先补齐再实现。

采用当前静态框架，不增加后端或前端构建依赖。按论文内容调整章节，不机械保留所有模板模块。移除全部示意文字、未使用的示例图和对应 asset manifest 条目；缺少真实素材的模块删除。论文、作者、单位、链接和 BibTeX 使用确认信息，未知主页不猜测。原 PDF 和 charts 保持不变。

对图表采用清晰、可追溯的导出素材；表格截图保留列名、单位和图例；重新计算首页数字。公开页面不出现版本更新或制作过程说明。统一字体层级、宽度、留白和自然断行；Teaser 定位句放在图下。比较组件只用对齐素材，支持鼠标、触摸、键盘，隐藏视频和画布停止。

完成后启动仅服务 site/ 的本地预览，执行静态检查和实际浏览器检查，修复明确问题。更新 source-map、decisions 和 review 记录。交付可预览的完整页面，本轮不推送或部署。
